How it works

  1. 1
    Send your plans.

    A PDF plan set with floor plans and elevations, plus sections and a roof plan if you have them.

  2. 2
    I build the house.

    Every wall, stair, ceiling, roof and opening comes from the written dimensions, and I check the sheets against each other.

  3. 3
    You get the results.

    Renders, elevations, sections, a walkthrough link you can share, and the plan check.

Plan check

I compare every sheet against the others while I build the model. On one recent house, the check found a stair with 72.7 in of headroom where the plans call for 80 in. The plan check is a list to review with your architect, not a code review.
